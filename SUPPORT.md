# Support

`grokbox` is an unofficial alpha project maintained on a best-effort basis.

- Usage questions and sanitized bug reports: GitHub Issues
- Feature proposals: GitHub Issues
- Security vulnerabilities: follow [`SECURITY.md`](SECURITY.md)
- Upstream Cursor, xAI, Grok Bot, Tailscale, or account support: contact the
  applicable provider; this project cannot manage provider accounts or policy

## Supported environment

| Role | Supported or tested |
| --- | --- |
| Source development | Linux and macOS with Bun 1.3.14 |
| Published-style CLI runtime | Node.js 20+ on Linux and macOS |
| Box daemon and host capabilities | Linux |
| macOS Keychain references | macOS only |
| Windows | Not currently supported or tested |

Undocumented Gateway, Sandbox, quota, and desktop integrations are experimental
compatibility surfaces. Before reporting breakage, include the grokbox commit,
operating system, and a sanitized `doctor` result. Never attach credentials or
raw product content.
