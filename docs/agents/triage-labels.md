# Triage Labels

Use these roles on GitHub Issues when the corresponding repository label exists:

| Label | Meaning |
| --- | --- |
| `needs-triage` | Maintainer evaluation is required. |
| `needs-info` | More information is required from the reporter. |
| `ready-for-agent` | The issue has bounded acceptance criteria and can be implemented. |
| `ready-for-human` | A human decision, credentialed action, or environment-specific validation is required. |
| `wontfix` | The issue will not be actioned. |

Labels are workflow hints, not product or implementation authority.
