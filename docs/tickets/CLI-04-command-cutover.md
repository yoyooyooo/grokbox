# CLI-04 · 完整命令面与旧入口去向收口

状态：能力范围与直接切换方向已接受，精确动作/参数及迁移证据待收口。依赖：[CLI-01](CLI-01-discovery-and-targeting.md)、[CLI-02](CLI-02-operation-contract.md)、[CLI-03](CLI-03-observation-and-wait.md)。本票保留整体切换义务，已迁移领域的实现与旧入口退出由 CLI-05 的 W3 和下述用例记录承接；不把合同讨论误写为当前没有施工。

## 用户结果

Agent 只学习一套正式命令，按自身策略组合基础能力。已有必要能力和数据都有去向，保护/交接等已接受的管理程序由后台按证据推进，调用者不承担内部 advance 循环。

## 已定范围与剩余工作

以[决策 D01、D08、D09、D10](../roadmap/agent-first-cli/decisions.md)、[候选目录](../roadmap/agent-first-cli/command-catalog.md)和[固定基线映射](../roadmap/agent-first-cli/migration-map.md)为入口：

- 项目尚未正式发布，用户期望破坏式重建。正式切换时旧语法直接退出，无对外兼容期；同批迁移仓内及已知调用方。
- 普通 CLI/Web 业务共用一个常驻管理服务，modeld 独立。bootstrap/生命周期、离线诊断和外部 Box 控制是明确例外，具体故障回执定位待补。
- Bot 模型可原生、跟随默认或指定。指定不跟随默认切换，但自身模型配置更新作用于后续轮次；仍被 Bot 选择或全局默认引用的模型拒绝删除，仍有跟随者时拒绝清空默认；无默认不能选择跟随，不擅自换模型。输入、引用检查并发和回执待细化。
- Memory、Project、文件的检索与修改纳入范围；候选写动作、字段、源 owner、并发及结果核验逐项定义，缺可靠写能力者只读。
- 默认保护、真实 Bot 前后继关联、证据决定交接范围、后台管理异常与启用后的自动通知已接受。不新增业务任务调度或跨工具人格身份。

## 验收产物

- 从拟实施基线重新导出 registry；按旧意图、参数分支、目标、权限和成功条件映射，解释保留、合并、拆分、后台接管或退役。182/182 名称覆盖不能替代语义覆盖。
- 每个候选 leaf 有事实/效果 owner、真实能力、成功条件和失败恢复。上层写能力已接受不等于批准对称 CRUD 或未验证上游调用。
- 走查 Bot 生命周期、模型、消息、Job、Memory/Project/文件、异常通知、系统维护和外部 Box；不规定调用者如何编排业务。
- 同批迁移 operator Skill、安装脚本、客户端、文档、测试、打包与已知外部调用方。内部施工可分阶段，但不发布两套正式合同。
- 明确旧语法退出、版本不匹配提示和数据兼容范围：原生数据/身份继续接入，必要配置一次性转换，旧开发期内部历史不承诺导入，投影/索引重建。识别实际在途或未知外部效果，防止重复执行；不将范围决定解释为自动清理。
- 旧 writer 被接管后有退出证据。已废弃的源码限制需重新核实，不能仅因“以前这样实现”永久继承。
- 同步目录、合同与映射，清楚标记未决项；交 CLI-05 与各来源票推进重建至 Web UI 的完整交付，不以 leaf 数量变少作为成功。
- 切换同批迁移 LIVE 的精确命令覆盖、执行手册示例、只读 probes、Skills、制品输入清单和相应测试。候选命令在实际 registry 注册前不放进可执行 probe；退役入口不得为通过旧测试而保留空别名。
- 验收范围依据新版产品义务，CLI/Web 不需要逐按钮对称，但页面所需读/写/订阅能力都有领域承接；不把缺实现改标可选。

## Job 领域切换（2026-09-22）

原 `exec run`、`jobs list/show/logs/cancel`、daemon Job RPC/启动与关闭接线，及旧 Profile process capability/Job 事件源已退出；源码不存在兼容别名或转发 writer。`job policy/start/list/get/wait/logs/cancel`、两个原请求查询域和 `/jobs` 共用原 Box Job manager、进程/文件权限适配及持久记录。执行、shell、观察、输出、取消权限独立；未知首次发布或取消不会因同请求、换代或诊断保留期限而获得第二次执行。完整说明、确定性反例与实际 Node/Chrome/制品验证见 [Job 管理报告](../reports/2026-09-22-job-management.md)。

未迁移的文件/桌面/Gateway 域仍有各自去向；现行 canonical 配置中的 `daemon.process/filesystem` 名称不是旧 daemon 的执行授权，后续配置命名收束不能复活旧执行器。此片不关闭 DATA-01 的完整文件/原生材料通路、全域观察关联或 W4 的服务宿主和集中验收。

## 文件领域切换（2026-09-22）

`file root list/get`、named-root的`file stat/list/read/write/mkdir/upload/download/delete/restore`、file领域原请求查询及暂存取消，已由共享客户端/Server和Web消费原Box文件适配。旧八个fs命令、14个daemon文件RPC、handshake/Profile文件权限承诺及旧CLI writer退出；原文本材料消费者仍走真实源owner，共用原材料安全库中的physical path互斥，不新建万能操作库。未知首次声明/发布/服务换代不能靠改配置或换UUID重放；二进制核验、原删除恢复和独立权限有实际Node/Chrome路径，见[文件管理报告](../reports/2026-09-22-file-management.md)。
