# WEB-01 · Web UI V0 视觉保存与功能纠偏

状态：V0 仅为历史视觉参考，最终风格尚未定稿，不是功能工程的前置。当前工作树保存三张图，第四张工作台原图缺失，见[资源记录](../design/webui/v0/README.md)。Web 工程与功能原型分别归 WEB-02/WEB-03，真实浏览器总责归 T29；本票负责后续视觉确认。

## 用户结果

未来设计与实现者能找到已有 V0 参考及资源缺口，理解哪些功能已被排除，并从页面元素追溯到真实数据来源；不把旧图片中的样式当作最终设计批准。

- [来源研究](../reports/2026-09-19-webui-source-feasibility.md)：官方形象、活动标签、Gateway 事件、Memory/Project 与现有后台差额。

## 后续细化验收

- 伙伴列表优先姓名、真实活动、状态与新鲜度，官方小头像只承担识别；不恢复大形象卡片网格。
- 暖白、柔和紫、疏朗排版和顶部导航仅作探索参考；最终风格由后续设计确认，不阻塞路由、功能和后台。
- 移除图里的聊天 composer、发起任务、审批回复、虚构阶段和无依据交付归因。
- 补齐 Memory/Project 检索与按来源能力开放的编辑、日志及未知/陈旧/断连/空状态；V0 四张图没有证明这些页面已设计。
- 模型选择区分原生、跟随默认和指定模型；保护/交接显示真实 Bot 前后继及证据缺口，管理异常和通知回执分别呈现。必要管理操作复用后台，不要求每个 CLI leaf 都有按钮。
- 原生数据、归一化字段和派生展示逐项区分；动画不假装任务进度。
- 功能浏览器与基本可访问性先由 [WEB-02](WEB-02-web-foundation.md)/[WEB-03](WEB-03-functional-prototype.md)验证；定稿后补视觉、响应式和体验回归，结果归 LIVE-WEB-VISUAL。静态图不是实现验收。

本票不成为新的 API/collector owner。后续视觉迭代另定版本，保留本 V0，不覆盖原图伪装历史。
