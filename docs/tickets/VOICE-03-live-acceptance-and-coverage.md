# VOICE-03 · 官方语音闭环验收与委托覆盖评估

状态：**deferred；未启动真实通话或角色策略实验。** 依赖 [VOICE-01](VOICE-01-route-and-host-qualification.md) 的路由/来源资格、[VOICE-02](VOICE-02-managed-execution-and-delivery.md) 的相关实现及受影响制品检查。范围与度量唯一见 [语音 Spec](../roadmap/voice-delegation-spec.md)；本票不把该独立后续事项加入当前 W4/W5 门槛。

## 目标

在未修改的官方客户端中，证明一次实际语音委托进入指定自定义 provider、复用原生 Bot 工具/状态、返回正确通话并被播放。技术闭环与语音模型是否主动委托分别评估；不因前者成功宣称每句话已经换模型。

## 窗口、位置与授权

启动时重新固定 App/Host/companion、运行代、有效语音 Harness 路由、目标 Bot 权威归属、实际模型/API 类别和捕获 revision。角色描述可消费不代表委托策略有效；磁盘 bundle 默认值不能代表账号开关。目标选择、模型费用、通话/麦克风及可逆测试动作进入明确窗口；不得从这次文档提交继承现场授权。

实际用例就绪后，同批更新 `docs/tickets/LIVE-integration-validation.md`、`docs/maintainers/live-end-to-end.md` 以及现有 `scripts/live-validation.mjs` / checklist 测试的相关覆盖。新增语音场景与本窗口绑定，不污染旧候选结果。固定取证写入 `docs/reports/`，只有 LIVE 保存当前现场结果，本票保留实施/资格差额。现在不登记尚不存在的语音命令或测试脚本。

## 核心闭环验收

- [ ] 正常首轮：预先设置无危险副作用、有独立可核验结果的材料/任务；证明委托→Box 原生 wake→受管捕获→实际 provider→原生工具/发送→正确 callId→客户端播放。不得仅靠模型自报身份或一个被念出的随机口令签收；工具结果、provider 记录和发送关联共同证明。
- [ ] 复杂纯推理与连续纠偏：不强行制造工具动作；核对委托保留必要背景、精确引用、禁止事项和更改对象。使用只有主工作会话掌握的受控上下文区分原生记忆复用与语音模型猜测；不复制用户私人历史用于公共证据。
- [ ] 忙碌时变更/停止：普通文字启动的受管 TURN 也能接收语音 steer；准确区分接受、step-boundary 交付和队列回退，不重复起同一任务。实际任务停止与单纯打断播放分开验收。
- [ ] 重复、超时、provider 失败与断连：unknown 先对账，未资格/失败不静默回官方；错误能沿受支持渠道返回，接口先说承接话不视为成功。重复请求与合理的“再检查一次”分别测试。
- [ ] 挂断和重拨：旧委托晚到、旧 call 关闭、同 Bot 新 call 已开、显式发送与 final-word 兜底、挂断记录/leftover wake 共同测试；不误投、不重复执行，转文字结果确有原生写入。
- [ ] 重启/换代与未受管对照：旧关联/迟到事件不能冒充新代；管理服务退出不主动杀合法 modeld 执行。未受管 Bot 保持原生路径，不为测试改执行归属。复用可用既有窗口证据，不无差别重跑所有 provider 矩阵。
- [ ] 分段测量延迟与交付：区分说完→委托、执行→首个有用结果、Host 事件→实际播放；即时 receipt 不是自定义首答。播放未知、被打断及仅部分听到分别记录；Host emit 不能单独证明用户听完。
- [ ] 对每项声明给出版本/来源、反例、关联事实与未观察层；清理仅限获授权测试材料并核对残留。所有原生关键出口未完成前，不以公共合成回放关闭整条能力。

## 独立候选评估：专业问题优先委托

这是可选策略研究，不是已接受的强制路由能力，也不是基础闭环的额外发布门槛。用户决定尝试时，仅通过小范围、可恢复的正常 Bot 角色配置比较前后；保存原值并恢复，不改 App、不改 Server 归属、不批量改 Bot。

评估集提前定义应委托的问题及判定方式，覆盖架构推理、项目判断、事实核验、连续指代/纠偏、长背景与禁止事项，并加入闲聊对照。分别记录委托覆盖、约束保真、已委托请求的受管执行、正确目标交付和实际播放；公开结果注明样本/分母/unknown。漏委托是覆盖缺口，不是绕过 Box 后也算自定义成功；工具次数增加不自动等于质量改善。

角色配置与客户端固定策略相冲突时保留结果，不使用伪造 context 字段或工具输出覆盖提示词作为工程契约。可独立记录该候选为未采用/效果不足，不倒退已经验证的委托后模型链；反之策略看似有效也不能跳过核心闭环。

## 完成边界与禁止

核心闭环只有对应 LIVE 场景和实际证据完整后才获所声明范围的资格；可选策略单列结论。不把接受方向、源码合入或一次绿色测试当作部署/费用/对外发布授权，不建设第二份现场状态表，不新增语音 UI、音频服务或业务编排系统。
