# Archive: retired design and bounded evidence

This area preserves useful explanations and audit history removed from current implementation routes. It is not a backlog, command recipe or authorization source. Current contracts start at [Documentation](../README.md); active work at [Tickets](../tickets/README.md); current live results only at [LIVE](../tickets/LIVE-integration-validation.md).

| Historical material | Why it is retained |
| --- | --- |
| [Runtime rebuild baseline](runtime-rebuild.md) | Exact recoverable pre-convergence source, retired layouts/phases and the mapping of surviving obligations |
| [Managed compact evolution](managed-compact-evolution.md) | Why late registration, pending summaries and timer-only fixes were insufficient; which old choices were superseded |
| [Milestone review residue](milestone-review-residue.md) | Fixed finding identities, later scoped closures and evidence ceilings; no permanent model-specific dispatch loop |
| [External session research](external-session-research.md) | Historical reference scope and recovery of the full source-pinned study without making it a current architecture authority |
| [Fixed verification reports](../reports/README.md) | Existing receipt store, retained at its stable paths because LIVE and receipt validators consume it |

Reports and archive have distinct roles. `docs/reports/` owns immutable verification windows, including a report that still supports a current LIVE result; this archive owns retired research/design/review narratives. A report is not copied into both directories. New current contracts and instructions do not belong here.

Exact Git recovery is used for committed repetitive plans rather than keeping an entire obsolete specification active. The baseline must actually contain the retired text; uncommitted work is never discarded under this rule. Original dates, failures, version scope and limitations remain unchanged. Historical evidence is not upgraded to current qualification by moving or summarizing it.

Unknown/failed effects and unresolved obligations survive in their current owning tickets. Private raw Host source, credentials, operational addresses and business transcripts remain outside the public repository; archive is not a privacy exception. See [documentation maintenance](../maintainers/documentation.md).
